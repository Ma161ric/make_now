# Collections implementation plan

## Phase 1
Create the minimal data model.
- Collection
- CollectionItem
- CollectionMode
- active flag

## Phase 2
Create the minimal flow.
- create collection
- add manual item
- activate collection
- show one collection-driven card in Today

## Phase 3
Implement collection analysis.
- infer themes from items
- infer likely intent
- infer recommended mode
- store derived analysis

## Phase 4
Implement suggestion engine.
- Explore suggestions
- Apply suggestions
- map suggestions into Today feed

## Phase 5
Improve UX.
- mode explanations
- better empty states
- better loading states
- done / skip / save-for-later feedback

## Phase 6
Add richer input later.
- share flow
- instagram import
- tiktok import
- pinterest import

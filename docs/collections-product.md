# Collections product spec

## Core idea
The app turns saved inspiration into relevant daily suggestions and small real-life actions.

## Main objects
- Collection
- CollectionItem
- CollectionMode
- CollectionAnalysis
- Suggestion

## Collection modes

### Passive
Store things only.
No active suggestions.

### Explore
Help the user discover more.
Examples:
- suggest related knowledge
- suggest adjacent interests
- suggest activities, concepts, or places

### Apply
Help the user act on saved inspiration.
Examples:
- suggest a small action for today
- suggest planning something for the weekend
- suggest trying one concrete behavior

## Core UX principle
The app should feel calm, useful, and specific.
It should reduce overload rather than create more.

## Important product rules
- collection titles can be weak or messy
- collection meaning should mainly come from contained items
- daily suggestions should be small and relevant
- the Today feed should surface one useful thing, not ten
- suggestions should not sound like generic self-help advice
